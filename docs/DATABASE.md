# 数据库与外部数据结构说明

## 结论

本项目**没有本地数据库、数据库表、DDL、ORM、JDBC 数据源、MyBatis Mapper 或迁移脚本**。`pom.xml` 也未引入数据库驱动或持久化框架。因此不存在可交付的本地“表注释、字段、索引”定义，不能虚构数据库表结构。

门户是无状态业务数据门户：SAP 为业务事实来源；飞书多维表格为登录授权配置来源；浏览器会话仅保存在应用进程内存中。

## 本地持久化结构

| 项目 | 实际实现 | 表/字段/索引 |
| --- | --- | --- |
| SAP 业务数据 | 运行时 REST/OData 读取或写入 SAP | 无本地表 |
| 供应商账号和权限 | 飞书多维表格记录 | 无本地表 |
| 登录会话 | `ConcurrentHashMap<String, Session>` | 无本地表、无索引；服务重启后失效 |
| SAP 查询缓存 | `VendorDataCache` 内存缓存 | 无本地表、无索引；按供应商和查询键隔离，过期或刷新后清除 |

## 飞书多维表格：Portal 登录授权

该表由飞书多维表格托管，并非应用数据库。项目按**字段显示名称**读取，因此字段名称需与下表一致。

| 字段 | 类型/格式 | 必填 | 说明 |
| --- | --- | --- | --- |
| 登录账号 | 文本 | 是 | 登录时精确匹配（去首尾空格）。 |
| 密码哈希 | 文本 | 是 | BCrypt 哈希，必须以 `$2` 开头；严禁填写明文密码。 |
| 供应商编码 | 文本 | 是 | SAP 供应商范围（LIFNR）。 |
| 供应商名称 | 文本 | 否 | 登录成功后用于显示。 |
| 状态 | 单选/文本 | 是 | 仅“启用”可登录。 |
| 生效日期 | 日期或毫秒时间戳 | 否 | 空表示立即生效；按中国时区比较。 |
| 失效日期 | 日期或毫秒时间戳 | 否 | 空表示不失效；按中国时区比较。 |
| 采购组织 | 多选数组或逗号分隔文本 | 否 | 登录主体的采购组织范围。 |
| 公司代码 | 多选数组或逗号分隔文本 | 否 | 登录主体的公司代码范围。 |
| 工厂 | 多选数组或逗号分隔文本 | 否 | 登录主体的工厂范围。 |
| 权限 | 多选数组或逗号分隔文本 | 否 | 可用 API 功能权限；缺失即不授予。 |

### 飞书表的索引说明

飞书多维表格的字段索引、视图、排序由飞书管理，应用代码没有创建或依赖任何数据库索引。登录服务会读取授权表记录并在应用内逐条匹配账号；账号量较大时，应在飞书侧维持合理的数据量、有效期和停用记录，而非在本项目中创建索引。

## SAP 外部业务实体

下表是项目实际使用的 OData 实体/导航数据，而不是本地表。服务 URL 与实体集可由 `application.yaml` 和环境变量覆盖。

| 领域 | SAP 服务/实体 | 用途 |
| --- | --- | --- |
| 供应商主数据 | `API_BUSINESS_PARTNER`：`A_BusinessPartner`、`A_Supplier`、`A_SupplierCompany`、`A_BusinessPartnerBank`、`A_BusinessPartnerContact` | 基础资料、地址、邮箱、电话、税号、公司代码结算信息、银行和联系人。 |
| 采购订单 | `api_purchaseorder_2`：`PurchaseOrder`、`PurchaseOrderItem`、`POSubcontractingComponent` | 订单头/行、交期、确认控制键、订单类型、外协组件、供应商及收货方地址。 |
| 外协组件描述 | `API_PRODUCT_SRV`：`A_ProductDescription` | 为外协组件补足物料描述。 |
| 内向交货单 | `API_INBOUND_DELIVERY_SRV;v=0002`：`A_InbDeliveryHeader` | 正常采购订单的 ASN/内向送货单查询和 ASN 创建。 |
| 外向交货单 | `API_OUTBOUND_DELIVERY_SRV;v=0002`：`A_OutbDeliveryItem` | 退货采购订单的送货单查询。 |
| 收货凭证 | `API_MATERIAL_DOCUMENT_SRV`：`A_MaterialDocumentItem` | 以 101/102/123/122 等移动类型计算净收货及结算候选。 |
| 供应商发票 | `API_SUPPLIERINVOICE_PROCESS_SRV`：`A_SupplierInvoice` | 发票查询、结算量计算与预制发票创建。 |

## 数据一致性与口径

- 订单未收货数量：订单数量减去净收货数量。标准订单净收货为 `101 - 102 + 123 - 122`；退货订单使用 `161 - 162`。
- 可发运量：订单数量减净收货数量再减未清 ASN 数量；完全交付标识订单不再提供可发运量。
- 可结算量：仅对可结算收货候选，基于收货数量、已结算数量及单位一致性计算；免费订单不进入结算。
- 所有 SAP 查询都由服务端加上当前供应商范围，浏览器不直接连接 SAP。
